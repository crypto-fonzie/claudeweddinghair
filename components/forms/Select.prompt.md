A native select with the system's square hairline treatment and a brass caret.

```jsx
<Select id="party" placeholder="How many heads?" options={["Just me","Two to four","Five to eight","More than eight"]} />
```

- Options are written the way a person would say them — "Two to four", not "2–4 pax".
- Use for short closed lists. For the budget band, use `ChoiceGroup` instead so all four ranges stay visible.
