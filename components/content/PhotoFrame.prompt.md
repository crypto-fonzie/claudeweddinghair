Every image on every surface. Square corners, no border, hard crop — and with no `src` it states which of the four repeating shot types belongs in the slot.

```jsx
<PhotoFrame shot="back-of-head" ratio="1 / 1" caption="Trial, natural light" />
<PhotoFrame src="/work/03.jpg" alt="Low chignon, veil fitted" ratio="3 / 4" />
```

The four shot types, in rotation: **back of the head** (the actual product), **hands working** (mid-pin, motion blur is fine), **the room** (robes, curtains, the mess), **the party** (bridesmaids and family, done and waiting).

- Never rounded, never bordered — unless it is a 1px Brass hairline.
- Natural window light, warm low-contrast grading. Never flash, never cool blue, never stock, never heavy retouching.
- Never post or publish a set without a back-of-head shot in it.
