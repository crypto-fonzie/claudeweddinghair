The small uppercase label that sits above every headline — section markers, image captions, table heads, deck eyebrows.

```jsx
<Eyebrow>How a morning runs</Eyebrow>
<h1 className="pp-headline">You get the schedule before we do.</h1>
```

- This is a *style*, not a third typeface. Any time a third face feels necessary, this is the answer instead.
- Always uppercase, always 0.22em tracking, always Tortoise (or Brass on Ink).
- Eyebrows go above headlines, never below. One per section.
