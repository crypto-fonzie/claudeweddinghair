A 1px hairline. It is the only divider in the system — there are no shadows or borders doing separation work anywhere else.

```jsx
<Rule />
<Rule tone="brass" />
```

- Default is Tortoise at 18% opacity. `faint` (9%) for rows inside a list; `brass` under a table head or between timeline rows.
- Rules run the full measure or the full section width — never a short decorative dash under a heading.
