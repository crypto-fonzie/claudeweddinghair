The only button in the system — solid Ink fill, square corners, uppercase Karla Medium 12px at 0.16em tracking, generous padding.

```jsx
<Button href="/enquire">Start an enquiry</Button>
<Button variant="secondary">See recent work</Button>
```

- Hover is a colour shift to Tortoise, nothing else. No lift, no shadow, no scale.
- `secondary` is a 1px Ink outline on transparent that fills on hover. Use one primary per view.
- `inverse` for Ink panels and the deck; `quiet` for tertiary links inside body copy.
- Copy rules apply to the label: no urgency, no exclamation, never "Book now". "Start an enquiry", "Ask about a date", "See recent work".
- Never round the corners, never add an icon that isn't the pin.
